# Arcby — Fusion 360 model

- Live document: **`Robot_v1`**, Fusion *Default Project* (cloud). Single component, many bodies
  (Selim refused multi-file assemblies). Snapshot exports: `cad/Arcby.f3d`, `cad/Arcby.step`.
- Fully parametric: see `docs/parameters.md`. Change parameters, not geometry.
- Timeline groups: Base Plate + Motor Brackets, Caster Pad, L298N Standoffs, Battery Strap Slots,
  Wheel Dummy, Wheel Wells + Wire Holes, Base Fillets, Test Pieces, Measuring Guides,
  Upper Deck + Pillars, Raspberry Pi Mount, Buck 1 Zip Slots, Camera Plate + Deck Fillets,
  Motor Pin Slots, Motor Dummies, L298N Dummy, Battery Under Plate + Switch, Buck Converters,
  Cable Management, Connector Stand-ins, Wiring (visual), Speaker + Microphone, plus later
  ungrouped features (pan-tilt, ultrasonic, Pi spacers, Wago changes, new wires), Encoder Test Pieces
  (+ Encoder Hub Fit dots; bodies at x 374-524, generated by script from the `enc_*` / `fc33_*` parameters).
- Body naming: `... Dummy` = stand-in for a bought part, `Test - ...` = fit coupon (hidden),
  `UNUSED - ...` = obsolete (hidden), `Wire - ...` = visual pipe for a cable.
- Suppressed on purpose: Extrude5, Hole2, R-Pattern1, Standoff Fillets (moved to separate L298N
  spacers), Pi Standoffs, Pi Pilot Holes (replaced by separate Pi spacers + clearance holes),
  Plug Cradle, Wago Pocket (moved to separate trays), and the old T-plug-era wires.

## Coordinate system
Origin centred on the base plate; +Y front (caster), +X right, Z up. Base plate top z = 3,
upper deck bottom z = 43, top z = 46 (z 19..46 including the ultrasonic plate).

## Driving Fusion from Claude (MCP `fusion_mcp_execute`, Python `run(_context)`)
- An "Untitled" doc may be active — always:
  `doc=[d for d in app.documents if d.name.startswith('Robot_v1')][0]; doc.activate()`.
- Save after each change: `doc.save('message')`.
- If no document is open (Fusion restarted), `app.activeProduct` is None: open `Robot_v1` with the MCP
  `document open` call (lineage `<design-lineage-urn>`); then use
  `design.parentDocument` (`app.documents` was empty in MCP scripts).
- Version 47 = the printed Base v1 (before Base v2).
- Read-only scripts: set `readOnly: true`.
- Hidden bodies export **empty** 3MF → set `isLightBulbOn=True` temporarily.
- Flip for printing: rewrite 3MF vertices (x, y, z) → (x, −y, zmax − z) (see `tools/export_flipped.py`).
- Edge-based fillets lose references when geometry changes — select by faces/features.
- Through-All cuts sometimes fail with "body not found" — use explicit distances.
- `TimelineObject.rollTo` can fail ("Associated feature is invalid") — prefer suppress + add new features.
- Interference check: `design.analyzeInterference`; wire↔terminal touches are expected.
- Bambu can be opened from a script: `subprocess.run(['open','-a','/Applications/BambuStudio.app', path])`.
- The Mac sometimes sleeps → tool timeouts; read-only calls can be retried, writes should be re-checked first.
